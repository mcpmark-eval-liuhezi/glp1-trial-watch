# glp1-trial-watch

Durable tracking home for our endocrinology group's **quarterly pipeline review**, themed this quarter on **GLP-1 receptor agonists in adults with type 2 diabetes**.

## What this repository is for

- Capture the **late-stage (Phase 3) recruiting landscape** for GLP-1 receptor agonists in adult type 2 diabetes in one durable, findable place on GitHub instead of scattered notes.
- Provide **one tracking issue per selected Phase 3 trial** (chosen by largest planned enrollment), each attached as a sub-issue of the parent summary issue.
- Record **aggregate landscape breakdowns** (by phase and by sponsor class) of the full recruiting search so the team can see the big picture at a glance.

## How the trials were selected

1. Searched ClinicalTrials.gov for **currently recruiting** studies of **GLP-1 receptor agonists** in **adults with type 2 diabetes** (28 studies returned).
2. Filtered to **Phase 3** studies.
3. Took the **three largest by planned enrollment** — all three Phase 3 studies in the result set qualified.

## Navigation

## Maintenance

For each quarterly review, re-run the same ClinicalTrials.gov search (condition: Type 2 Diabetes; intervention: GLP-1 receptor agonist; status: recruiting; adults), refresh the Phase 3 selection and aggregate counts, and update this repository accordingly.
