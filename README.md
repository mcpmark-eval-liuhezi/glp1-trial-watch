# GLP-1 RA Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

This repo captures the late-stage recruiting trial landscape for GLP-1 receptor agonist studies in adults with type 2 diabetes:

-精选 recruiting Phase 3 trials with the largest planned enrollment, pulled from ClinicalTrials.gov (condition: type 2 diabetes; intervention: GLP-1 receptor agonist).
